# Painterly 2.5D

**Blender 5（EEVEE）用・ワンクリックで手描き風 2.5D に。** 明暗の境目に筆タッチが入るトゥーンシェーディング、2コマ打ちでゆらぐ手描きアウトライン、油彩風ポストエフェクトを、どんなシーンにもボタンひとつで適用します。

[English](README.md) | 日本語 | [简体中文](README.zh-CN.md)

![ビフォー / アフター](docs/images/hero_before_after.jpg)

## 特長

- **Make It Painterly（ワンクリックで絵画風に）**：EEVEE設定、全マテリアルのトゥーン化、アウトライン、コンポジターまで一括で行います。
- **どんなシーンでも動く**
  - マテリアルのないオブジェクトには自動でマテリアルを作成します（頂点カラーも保持）。
  - Diffuse／Emission／画像だけ／ノードグループのマテリアルも、元の色を引き継ぎます。
  - ガラスや半透明の面は、元のシェーダーのまま残します。
  - コレクションインスタンス（アセットブラウザ／リンク素材）にも対応しています。
  - 一番強いサン（なければ被写体を最も照らすポイント／スポット／エリアライト）をキーライトに使います。ライトが1つもなければ、カメラ側からのサンを自動で追加します。
  - **シーンのスケールに合わせる**：オブジェクトの大きさとカメラ距離から、筆タッチの細かさ・フォグ・線のフェードを自動設定します。10cmの小物でも50mの建物でも同じ見た目になります。
  - **環境光の補正**：明るい空やHDRIの下でも、明暗の分かれ目を保ちます。
- **トゥーン＆筆タッチ**
  - キーライト基準で正規化されたセル分け。
  - 固有色（HSV）から作る色付きの影。
  - 明暗境界だけに入る筆タッチ。
  - リムライト、テクスチャ発光（窓・ランタン）。
- **アウトライン**
  - ジオメトリノードの反転ハル（画面上で一定の太さ）。
  - 遠景フェード、途切れる手描きの太さ、2コマ打ちのゆらぎ。
  - UVシームは自動で溶接し、平らな地面はスキップします。
- **ポストエフェクト**：深度フォグ、線を守る2段の桑原フィルタ、影の網点、暖色ブルーム＆ハレーション、紙の質感、レンズのほこり、フィルム粒子、色収差、周辺減光、レトロなグレーディング。ピクセル単位の値はすべて解像度に合わせて自動調整されます。
- **プリセット**：
  - ブルーアワーの夜
  - ゴールデンアワー
  - パステルスイーツ
  - 絵本の昼
  - クリーン／プロダクト

  どれも自分に関係する値だけを変更します。
- **オブジェクトごとの上書き**：しきい値・影の明るさ・筆タッチ・発光・線の太さを調整できます。マテリアルを共有していても個別に設定できます。
- **安全・元に戻せる**：値はシェーダー内で読み取るため（フレームハンドラなし）、レンダーファームでも安全です。アドオンがない環境でも同じ見た目でレンダリングできます（保存時にアクティブだったシーンの値を記録）。「絵画風を解除」で元のマテリアル・コンポジター・表示設定に戻ります。
- **UIは英語・日本語・簡体中国語**：「プリファレンス › インターフェイス › 翻訳」の設定に従います。

## インストール

1. [Releases](../../releases) から `painterly_25d-x.y.z.zip` をダウンロードします（解凍しないでください）。
2. Blender 5.0 以降で **編集 › プリファレンス › Get Extensions** を開き、右上の **⌄** メニューから **Install from Disk…** を選びます。
3. zip を選べば、インストールと有効化が完了します。

![Install from Disk](docs/images/install.jpg)

## 使い方

1. シーンを開きます（モデルやマテリアルは何でもOK）。
2. 3Dビューで **N** キーを押して **Painterly** タブを開きます。
3. **Make It Painterly** をクリックします。ビューポートがレンダープレビュー＋コンポジターに切り替わります。
4. **プリセット**を選び、「トゥーン＆筆タッチ」「アウトライン」「ポストエフェクト」で微調整します。
5. **F12** でレンダリングします（EEVEE）。

![パネル](docs/images/panel.jpg)

| オプション | 内容 |
|---|---|
| 選択したオブジェクトのみ | Make It Painterly を選択中のものだけに適用（初期設定は表示中のシーン全体）。選択外のオブジェクトと共有しているマテリアルは、そちらも変わります |
| キーライトがなければ追加 | ライトが1つもないとき `P25D Key Sun` を追加（「絵画風を解除」で削除） |
| シーンのスケールに合わせる | オブジェクトの大きさとカメラ距離から筆タッチ／フォグ／線のフェードを設定 |
| シーンに合わせる（ボタン） | カメラ移動やスケール変更のあとに再調整 |
| 絵画風を解除 | 元のマテリアルに戻し、アウトラインを削除、コンポジター・レンダーエンジン・表示設定を復元（シーン全体、または「選択したオブジェクトのみ」がオンなら選択中のみ） |
| 初期値にリセット | 見た目の設定をすべてリセット |

### ヒント

- **筆タッチが大きすぎる／小さすぎる** →「シーンに合わせる」のあと「筆タッチの細かさ」（1mあたりの数）で調整します。
- **全部明るくて影が出ない** →「環境光の補正」を上げてください（明るいワールドやHDRIは補助光が強いため）。
- **商品のターンテーブル** →「クリーン／プロダクト」で油彩を控えめにできます。
- **一部の線だけ太い** → オブジェクトプロパティで「上書き」をオンにして「アウトライン太さ倍率」を下げます。
- **窓やランタンを光らせたい** →「テクスチャ発光」を上げます（シーン全体／オブジェクトごと）。

## 仕組み

```
マテリアル  : Diffuse → Shader to RGB →（放射照度 − 環境光）/ キーライト強度 → セルランプ
             ＋ 明暗境界付近の Voronoi 筆タッチ法線 ＋ 固有色からの HSV 影色
アウトライン: ジオメトリノード反転ハル。太さ ∝ カメラ距離（画面上で一定）、
             ノイズで途切れる太さ、ゆらぎ = floor(frame / rate)
コンポジター: フォグ → 桑原 ×2（AOVで線を保護）→ 影の網点 → ブルーム/ハレーション
             → 紙 → ほこり → 粒子 → 色収差 → 周辺減光 → グレーディング
```

## 制限事項

- EEVEE 専用です（Shader to RGB は Cycles 非対応のため）。
- アウトラインはメッシュオブジェクトのみです。カーブやテキストはトゥーン化されますが線は付きません（線が必要ならメッシュに変換してください）。
- スケッチ線（ラインアート）は重いシーンでは処理が重くなります。アニメーションではベイクを推奨します。
